# TV Damage and Overdue Lab windows

Release 20261101-tv-overdue-1 adds an account-specific overdue window to the existing tv.html display. Existing accounts retain Damage only until an administrator enables the new view.

User Access > Greenloop Accounts > selected account > TV display provides two window ticks: Damage Report and Overdue Lab & Glass cards + phone details. Select either one for a continuous single window, or both for alternating windows. Default durations are 10 seconds each; each can be set independently from 5 to 3600 seconds. Pending days default to 2 and can be changed from 1 to 365 whole days. At least one window must remain enabled. The same employee allowlist applies to both views, including its explicit empty-list behavior.

Only assigned employees with currently pending phones strictly older than the configured days limit appear in the overdue view. No zero-count or on-time employee cards are rendered. Names and phone counts are centered. A gentle red pulse marks each overdue card, with a static highlight when reduced motion is requested. A phone is counted once regardless of its number of requested parts or work lines. Unassigned phones are excluded from these employee cards.

The clock uses the existing verified Lab stay reader, including the original-arrival clock across Final QC returns. Final QC, Ready Stock, supplier-return holds and other phones no longer pending in Lab / Glass are excluded. A missing Lab arrival is never invented. The threshold changes this TV account's overdue display; it does not alter historical workflow data or the Dashboard's existing 48-hour report.

Click an employee card to open that employee's overdue phone table: IMEI1, model, GB, color, initial BH, supplier code, department, original Lab arrival (UAE) and elapsed time. Twenty phones are shown per page. Switching pauses while details are open, and resumes with a full configured interval after Back to employees. Manually opened damage history also pauses window switching; the original five-second damage employee Auto View remains separate. An explicit Pause switching button is available when both windows are enabled.

Counts and settings refresh every 30 seconds, on reconnect, on Refresh now, and when the overdue window opens. Configuration changes clear old cards and phone details before loading the new selection. Turning Damage off also clears its cached DOM, rows and summaries. Delayed responses from a former selection are ignored. Office Only lock, session expiration and sign-out stop the rotation and pending reads. On a failed settings check both views hide until permissions can be verified.

Server checks require active Damage TV View plus the new damage_report/overdue_pending read capability and an enabled overdue window. Cards, totals and direct employee-detail requests are scoped to allowed employees before aggregation; a hidden or unknown employee returns no phone rows or name. No supplier/customer names, parts prices, costs, entry, PDF, download or other operational access are granted. Damage-only accounts cannot fetch overdue phone data. Pending-only TV accounts cannot fetch the three damage TV readers or ordinary damage/PDF endpoints.

The new atomic access-save RPC validates the complete TV configuration and uses independent rotation and existing account/office revisions. Stale updates roll back account permissions, employee selections, network settings and TV configuration together. Private settings and change audit tables use RLS and have no browser grants. Existing damage validation and its database constraint are preserved: pending-only TV accounts can keep all actual damage-field permissions off, with their desired choices stored in the rotation settings. Existing settings and histories are not backfilled or deleted.

Install with outputs/Publish-GreenLoop-TV-Overdue.ps1. Paste the copied SQL into a NEW Supabase SQL query. Required result: installed_tv_overdue_version = 20261101-tv-overdue-1. The cumulative publisher checks previous installations and only asks for missing installers. No new Edge Function, JWT change or secret is required. After publication, use Ctrl+F5, select the TV account in User Access and save its desired windows, seconds, days and employees.
