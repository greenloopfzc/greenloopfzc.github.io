# Current per-phone return details

Reports saves an individual supplier-return correction to that return record. The Stock Return and Stock Replacement phone readers previously inherited the original immutable group reason instead. A saved correction could therefore remain absent in the sidebar while another phone still displayed the original group description.

Migration302 makes phone rows use that exact supplier return's current reason and notes. The original group record remains unchanged for audit. Replacement-group search includes a bounded array of current individual return details, so searching a newly corrected note finds its existing group without changing group-level counts. Individual phone rows remove that shared array and expose only their own current return fields. Linked replacement IMEIs, received/pending totals, stock allocations and original receipt quantities remain unchanged.

Returned rows show their current description even when a replacement link exists; the link remains visible separately. PDF and Excel Status / Link cells include the same description and link. Excel sizes the notes column and row heights to preserve longer notes. A saved workflow correction refreshes a visible sidebar through the existing workflow event or cross-tab storage signal; focus/manual refresh remain supported. Every path stays read-only and retains existing view/search/download/name/network grants.

The atomic installer patches only reviewed read functions and updates integrity receipts only when the recorded before-definition matches. It handles Windows CRLF paste formatting, remains repeatable, preserves prior installation markers and changes no business data or permission assignments. Expected result:20261113-return-details-sync-1.

In Reports, Add to changes prepares a draft. The final Save changes action, with its required reason/code, commits it. This display fix does not automatically save drafts or reapply a user's correction.

Validation reproduces the stale sidebar after an actual save_full_imei_workflow_v2 correction on one of two returned phones, with a replacement linked to the untouched sibling. After the installer, both sidebars show the corrected phone's note, the sibling retains its own note/link, search finds the new text, counts stay2/1/1, full export agrees and a subsequent edit invalidates an older export snapshot. Atomic failure/repeat installation preserves stock, return/group/receipt/allocation, correction audit and user snapshots. Chrome checks read-only sidebar refresh, links, name privacy and office lock. Actual PDF/Excel exports include current text; normal and long-note PDF pages are rendered and visually inspected, all text stays inside paper margins, and long-note Excel row heights adapt. No live database correction or publication is made by Codex.
