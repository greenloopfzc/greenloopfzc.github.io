# Returned phones in Initial QC grading analysis

An original phone already returned to its supplier must not appear again in Initial QC pending, Grade missing after QC or QC record missing totals or their detail lists. The saved supplier-return record, as well as the returned workflow status, identifies a returned phone. This rule applies to every selected batch, supplier and invoice scope.

SQL314 changes the shared canonical grading reader, so on-screen counts, percentages, clicked TOTAL lists and complete PDF export use the same rule. Returned phones remain in the original receipt/entered quantity and Returned list. Existing verified initial grades, Glass/Polish requirements and return/replacement history remain intact. A returned phone without initial grading evidence stays Not recorded; the report records it internally as returned_ungraded and explains this separately instead of inventing a grade or showing an actionable QC exception. Thus graded + genuine pending/missing + returned without recorded grade still equals entered Qty. Returned totals can overlap historical graded/work counts.

The returned detail list describes these phones as Returned; grading not recorded. Company phones with genuine QC waiting, missing grades or missing QC records continue to appear in the appropriate categories. Replacement devices remain excluded from original-stock Initial QC analysis. No phone, job, QC, return, grade or receipt quantity is repaired, deleted or rewritten by installation or reading the report.
