# Clickable grade totals

Each numeric TOTAL cell in Grade & required work and Percentage analysis opens the matching phone list. Qty includes all entered phones; A/B/D, Other grades and QC / grade pending use the existing analysis categories; Glass and Polish use the same canonical work flags and can overlap. Glass aliases remain one part and each phone is counted once. Percentage totals open the underlying phone count, not a separately rounded count. Zero totals open an explicit empty list.

Every IMEI occupies exactly one table row with separate S.No, IMEI, model, GB, color, GL grade, battery, required Glass/Polish, supplier, original stock/batch quantity, invoice, current stage, QC pending, return status and received-date columns. Cells do not wrap into multiple lines or mobile cards. Content determines column widths; only the table scrolls sideways. It explicitly opts out of the generic workspace fit/card conversion. Dates omit time and there is no device-number column. Pages contain at most50 phones and serials continue across pages.
