# Daily Production stock card labels and alignment

Stock report names return to Total Stock, Grade A, Grade B, Grade BA and the equivalent label for other grades. RMA is labeled RMA Stock, without Grade. Matching report headings and date-report scope labels use the same names. All stock cards center their main names, quantities and supporting captions, including Daily Production and Last Day Total Stock when present. The icon/action row keeps its existing layout.

Only display text, text alignment and cache tags change. Counts, grade IDs, stock calculations, selected-card highlighting, permissions and raised card styling remain intact. No new SQL or Edge Function is required; the publisher includes any pending preceding Receipt Return Count installer and its tested retry handling.
