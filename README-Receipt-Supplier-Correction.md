# Change Stock Supplier

Reports → Stock Receipt Correction now has a separate Change Stock Supplier form. Choose the original receipt, select the correct existing active supplier, enter a reason, Review supplier change, then Confirm supplier correction. The existing quantity form stays separate. Save/clear one correction before preparing the other, so an unrelated draft is not discarded.

The review shows Current → Correct supplier, exact batch/invoice, original received quantity, linked phones/jobs, return records and replacement receipts. Selecting or reviewing never writes business data. A changed receipt, supplier, workflow, replacement membership, custody or box snapshot requires a fresh review. Uncertain responses retain the reviewed command and actor-bound request ID for a safe retry.

The protected atomic save changes only canonical supplier IDs on the original receipt, actual descendant receiving batches, linked jobs and associated supplier-return records. It does not rename a supplier globally or move phones between receipts. Original quantities, batch/invoice/IMEI identities, grades/BH, work, parts, return status, allocation/receipt commands, frozen return/Chaman snapshots and unrelated stock remain intact. Current Stock/Accounts/Reports/PDF data uses those canonical links. Current Chaman reports and receiving previews resolve corrected supplier labels without modifying original dispatch snapshots. Supplier Return screens resolve the current corrected link while preserving the original source snapshot and events.

An exact immutable audit records the complete before-scope, old/new supplier identity, reason, actor and UAE date/time. Per-phone correction events feed IMEI Search's existing masked old/new history. Supplier history is a snapshot-checked50-row report, independent of existing quantity history. Historical original supplier evidence remains in the private audit and earlier workflow records. Original receipt quantities and per-receipt supplier/batch labels are preserved.

This authorized supplier-only correction must not reopen exported boxes or undo stock-out. A narrow transaction/actor/row-hash proof keeps existing box state, print/verification evidence and phone status unchanged while appending a box source-correction audit. Other source edits retain the original mandatory source-recheck behavior. Temporary proof rows are private and removed before a successful return; any failure rolls back the complete command. Indexed per-row proofs avoid repeatedly parsing the full batch audit for every phone.

New independent Reports action: Correct stock supplier (audited). Existing receipt view plus Reports Edit and this explicit action are required; quantity correction alone grants no supplier write. Eligible Owner/Super Admin receipt viewers receive the new action initially. Other users must be granted it in User Access. Existing active-staff, TV-only, Office/network, supplier-name and independent read/write restrictions remain enforced on the server. Missing/malformed reads show an explicit unavailable/reload state and cannot become a zero-count preview.
