# Chaman Shop

Company/shop transfers with explicit workspaces. Owner and Super Admin can use all four actions. Other users need View plus exactly one User Access choice: Greenloop workspace or Chaman workspace. Entry and Download remain separate grants; existing staff receives no automatic access. All RPCs enforce active accounts, office access and the permitted side independently of the browser. No sales or customer-account features are included.

Two action cards per workspace: Greenloop has Send to Chaman / Receive Returns; Chaman has Receive Stock / Return to Greenloop. Admin sees all four actions. Stock and Transfer History are separate tabs, with a compact On the Way / At Chaman / Returning strip. Delivery/return cards retain reference, date, partial receiving and Sent/Received/Pending quantities. Phone rows include IMEI, model, GB, color, GL Grade and original supplier/batch quantity. No sales process.

Reports → Chaman Transfer Correction is Admin-only. Edit date/notes, undo receiving, remove selected mistaken IMEIs or delete a transfer. Every correction requires a reason, a current reviewed snapshot and a stable retry key. Deletion preserves private before/after audit and old phone details; Deleted History links to deleted Chaman transfers. Removing an outbound phone restores its original company status; removing a return keeps the phone at Chaman. Undoing company receipt removes it from company stock again. Completed receipts can only be reversed when the original phone/job/batch/status is unchanged and no later trip, active job or export-box reservation exists. An immutable custody sequence prevents a corrected display date from bypassing the later-trip check.

Stock effects: send immediately removes phones from company stock; shop receipt confirms its own physical balance; return dispatch remains outside Greenloop stock; only scanned Greenloop receipt restores each phone's saved workflow status. Original receipt quantities remain unchanged. Supplier Stock, IMEI In-company/Ready, receipt balance and Supplier Progress separate Chaman/transit phones. A phone cannot be sent twice or inserted into another company job/export box while off-site. Active work/box reservations block dispatch. Original batch/job records are preserved through multiple trips.

Tables and transfer cards use 50-record pages. Explicit pasted/scanned trays preserve all supplied IMEIs. PDF View/PDF/Excel downloads include the complete filtered result and reject changed snapshots. Dates display without time. Names retain the existing partner-name permission.
