# Parts Usage Report

Reports has a separate Parts Usage Report card. Its main table groups actual recorded parts by original Supplier / Batch / Model / exact Part name. Model grouping combines GB and color variants; View IMEIs shows one phone per row with Model, GB, Color, GL Grade, part quantities, technician and recorded date. Supplier, batch, model, recorded part, issue/manual date and text filters apply on the server before totals and pagination. Both summary and phone views show 50 rows at a time. PDF View, Download PDF and Download Excel export the complete matching selection.

The mint header uses #C1E2D2. Supplier and batch labels use each original receipt quantity; supplier names retain their existing separate visibility permission. Replacement-allocation batches resolve to their original receipt for this report. Returned/replaced phones can retain historical usage; the distinct physical phones in this usage history are not an original-unit inventory balance. Retired generic Housing and every recorded variant remain visible in historical usage under their exact recorded name.

Issued is the sum of real part-issue transactions. Installed counts confirmed linked installation records plus standalone manual installations. Joining several installation records never duplicates their parent issue. Manual installations do not invent an issue transaction. Returned means the confirmed transaction return quantity, and Net issued equals Issued minus Returned. These history measures can overlap; Installed is not inferred from an issue or from Final QC. The report shows actual recorded batch jobs and replacement jobs, not requested-but-unissued requirements. Dates filter the original issue, or the manual installation; linked installation quantities reflect the recorded history for the selected issues.

Recorded requested technician is preferred; where absent, the linked Parts order/manual work step supplies its recorded assigned technician or exact roster identity. Missing identity remains Not recorded. No prices, costs or currencies are returned by this report. Stock Parts Cost and its confidential permission remain independent.

The backend computes the selected transaction set once per request and aggregates installation rows once. Public readers are bounded to 50 rows; only the separate authorized export reader returns all matching rows. Parent/detail/export snapshots include immutable issue/manual IDs and current row values, so changed names, quantities or membership reject stale reads even when totals remain equal. The browser clears records and previews on office lock, sign-out, permission changes or report unmount, and ignores late responses.

SQL316 adds independent read-only Reports capabilities: parts_usage, parts_usage_search and parts_usage_download. Owner/Super Admin accounts with existing Reports view receive the new capabilities. Existing other users retain their prior choices and need an explicit User Access grant. Server checks active staff, Reports view, section view, section search/download, office restrictions and partner-name access; private helpers are not callable by authenticated or anonymous users. The new reads do not grant confidential costs or any entry/edit permission.
