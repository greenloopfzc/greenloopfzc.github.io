# IMEI Search position

The empty search page now starts below the top navigation instead of centering the heading and search form vertically in the available screen. Search form width, input and button height, styling, permissions, lookup behavior and result order remain unchanged.

Visual inspection covered desktop light/dark, mobile, and a loaded device result. Before/after form width, form height and input height matched. CSS root and css/ mirrors match. No new SQL or Edge Function changes are required for this layout change. The publisher verifies or includes any pending prerequisite iPhone Entry Options installation from the preceding release.
