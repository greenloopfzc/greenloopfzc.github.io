# Initial QC PDF design

UI release: 20261030-qc-pdf-design-1.

Initial QC Print, PDF View and Download PDF now share the Damage Report's real Greenloop logo treatment, white A4 portrait page, green/grey palette, understated rules and compact table. The brand is the primary heading element. Technician details are a legible 11-point secondary block rather than an oversized heading; total phones have their own restrained summary card. Prepared UAE date/time aligns with the document title. IMEI remains prominent within the table, with wrapped parts/services and light alternating rows. PDF table/brand/technician headings repeat on every page, with page numbers and an aligned total on the final page. Long technician names wrap in their card, and long single-phone work lists can continue without a fixed page limit.

The existing JPEG logo is embedded in PDF output and cropped with the same bounds as Damage Report; no business data is embedded in the logo. Print embeds those same bytes as an inline image, waits for the logo to load and rechecks the session revision before opening the print dialog. Missing logo/library errors preserve the session and re-enable outputs. A blocked popup is explained. PDF View still uses the same downloadable PDF bytes and existing object-URL cleanup. Print, View and Download keep the Initial QC Entry permission, saved-session-only records, mixed-technician English warning, unassigned-phone check, in-progress-save locks and office-lock clearing.

Only the handover rendering module, output controller and Initial QC script cache versions change. The Initial QC intake/workflow/parts routing code, permission catalogs and database installers remain byte-identical to the Stock Parts Cost release. No new SQL, Edge Function or JWT change is needed for this design update. The cumulative publisher still checks earlier installed database versions and stops on changed definitions or newer unreviewed Git history.

Offline validation uses five generated portrait PDF samples, a browser Print PDF and the saved-session browser cases, including mixed assignments, failed saves, view-only restrictions, logo/PDF-load failures and a changed list during print preparation. Poppler renders and PDF text/geometry checks cover the actual logo, all 120 phone IMEIs in a multi-page report, all 120 long service labels, page numbering and table-cell bounds. A separate sample PDF uses clearly labelled fictional entries. No live QC entries, assignments or stock were created or changed.
